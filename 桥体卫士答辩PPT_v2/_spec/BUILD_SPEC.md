# BUILD_SPEC —— 桥体卫士答辩 PPT v2 构建规范（唯一权威）

> 所有产出物必须严格遵守本文件。坐标系、颜色名、字体字号、元素 schema 一旦违反，构建脚本会报错并拒绝生成。

## 0. 交付目标

- 15 页（含 1 页视频占位页，见 §6 第 6 页），12 分钟，单人主讲，**现场不用硬件**（现场只跑软件：模拟数据源 + 浏览器 3D 大屏）。
- **全部视觉为矢量绘制**（PPT 原生形状 / 文本框 / 表格 / 折线）。**禁止使用任何位图截图、PNG、外部图片**。
- 设计语言：深蓝科技 + 青绿强调（工程感、可信感），比原 PPT 更有视觉冲击，比学术模板更现代。
- 全部内容必须能被仓库代码 / 测试 / 文档验证。**禁止编造数字、比例、用户量、效率提升百分比。**
- 口径红线：不说"数字孪生"、不说"AI/机器学习/预测"、不说"大数据"、不说"工程级精度/微应变(με)"、不说"真实桥梁监测"。统一用"三维可视化监测场景""缩尺模型受载模拟""相对应变指标（无量纲）"。

| 顶部标题带 | y = 0 … 1005840（0.0–1.1in） |
| 正文区 | y = 1188720 … 6035040（1.3–6.6in），可用高 = 4846320 |

| 内容区 x 边界 | 左 685800 / 右 11506200 |

**溢出硬规则**：任何元素必须完全落在内容区边界内。文字必须能放下：
- 中文按 1 em/字，英文/数字按 0.5 em/字估算宽度；`估算宽度 = (中文字数 + 0.5×非中文字符数) × 字号pt × 12700`，必须 ≤ 元素宽 × 0.95。
- 单行文本框高度 ≥ 字号pt × 1.55 × 12700；多行按行数累加。
- 一页正文总字数（不含页眉页脚）≤ 260 字。

## 3. 字体与字号

- 字体族：`微软雅黑`（中文）与 `Segoe UI`（数字/英文）都用同一 `font` 字段；渲染时优先雅黑。
- 字号阶梯（pt）：`display 66` / `hero 40` / `h1 27` / `h2 18` / `h3 15` / `body 13` / `small 11` / `tiny 9` / `kpi 32` / `kpi_sm 22`
- 行距：1.25；字距：大标题 2–3pt。
- 正文字号不得小于 11pt（投影可读性底线）。

## 4. 标准页眉 / 页脚（构建脚本自动生成，规格里不要重复写）

- 页眉：左上 `textual` 小节标签（`small`，`teal`，字距 2），其下 `h1` 页标题（`ink`）；页眉带底部 1pt `line` 描边，y = 1005840。
- 页脚：左 `桥体卫士 · 桥梁结构健康监测缩尺原型`（`tiny`，`slate_light`）；右 `NN / 15`（`tiny`，`slate_light`）；页脚上方 1pt `line`。
- 例外：第 1 页（封面）、第 14 页（价值总结）、第 15 页（致谢）`chrome` 设为 `"none"`，不加标准页眉页脚，整页归图形使用。**金句只出现在第 14 页 `s14_value`**（第 13 页 `s13_boundary` 是诚实边界矩阵，不是金句页）。

## 7. 事实口径（已由 Lead 从仓库核实，不得改写数字）

- 规模：核心 Python 约 1500 行（`app.py` 450 / `datasource.py` 223 / `db.py` 177 / `rules.py` / `config.py` / `firmware/main.py` 187）+ 前端模板与静态资源；Python 模块 6 个。
- 后端路由 19 条（`app.py`）。
- 6 类可解释规则（`rules.py` 已核实参数默认值）：阈值超限（`threshold=120.0`）、变化率突变（`rate_limit=10.0`）、持续超限（`duration_points=5`）、短时波动、基线偏移（`baseline_window=30`、`drift_limit=20.0`）、设备离线；分级阈值比例 `≥1.2×` 严重 / `≥1.1×` 报警 / 其余预警；每条报警带「触发规则 + 触发值 + 原因」；边沿触发 + 滞回（`_drift_fired` 等标志位）防刷屏；reason 文案自带"相对应变指标，无量纲"口径。
- 风险分级（以代码为准，`rules.py:43-46` + `app.py:48-49`）：**正常 / 预警 / 报警 / 严重报警**（对应 green / amber / orange / red）。注意不要写成「安全」，也不要漏掉「报警」二字。
- 数据源双模式：`DATA_SOURCE=sim|serial` 环境变量一键切换；模拟 6 场景（正常/预警/报警/严重/离线/恢复）；串口模式心跳 + 连续超时计数 + 最近错误原因，断线如实「设备离线」。
- 数据模型：SQLite **五表**（`db.py` 已核实）= `samples` / `alarms` / `settings` / `audit` / `device_heartbeat`；含 3 个时间索引（`idx_samples_ts` / `idx_alarms_ts` / `idx_heartbeat_ts`）。**注意不是 heartbeats / audit_log。**
- 鉴权与安全：密钥走环境变量（`.env.example`）、统一鉴权、未登录 API 返回 401、CSRF 防护；口令**支持** SHA-256 哈希校验（`config.py:66-70`），但默认是明文回退（`config.py:36` + `.env.example:11`），所以只能说「支持哈希存储」，**不能说「只存哈希」**。
- **测试数字（Lead 2026-10-02 实跑，直接引用，禁止改写；只报 passed 数与文件数）**：`python -m pytest tests/ -q` → **101 passed in 15.38s**（0 failed / 0 skipped）。测试目录 11 个文件 = 10 个 `test_*.py` + `conftest.py`。**禁止自行写 101 或 28 之外的数字。**
- 测试文件 11 个（`tests/test_*.py` 共 10 个 + `tests/conftest.py`）/ 用例分布按 `tests/` 实际统计。
- 三维场景：three.js r160 + OrbitControls 本地化（`static/vendor/`，离线可用）、花江峡谷大桥按公开设计参数建模（主跨 1420m 双塔单跨钢桁梁悬索桥）、旋转/缩放/平移/双击聚焦、5 个预设视角、结构线框与测点标注、颜色与涟漪节奏随风险等级联动、WebGL 不可用降级二维示意图。
- 手机端：服务端按 User-Agent 302 → `/trend`，客户端 ≤768px 视口兜底；桌面端 3D 页不受影响。
- 离线：ECharts 与 three.js 均本地化，断网可跑；串口不依赖网络。
- 1 秒采样周期（可调 0.1–60s），实时曲线保留最近 60 点。
- 现场演示：模拟数据源 + 浏览器 3D 大屏，**不含硬件实物**；PPT 不出现硬件实物页，仅在第 4 页用一句话说明真实硬件链路已实现、本次按软件模式演示。

## 8. 写作风格

- 标题动词化、有结论（例："6 类可解释规则 —— 每条报警说清为什么"）。
- 正文短句，每点 ≤ 22 字；数字前置。
- 每页底部（构建脚本生成）不放金句，金句只出现在第 13 页。
- 不写"我们认为/大概/可能"；不写无法验证的形容词（"业界领先""革命性"）。
