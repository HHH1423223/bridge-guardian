### 第一章 设计理念

- 原则一（颜色即语义）：`laneGlow / railGlow / edge / glassEdge / concreteEdge / rockEdge / beacon` 全部取消风险着色，正常态只剩中性灰 + 一个 8px 绿点。
- 原则二（诚实表达不确定性）：离线时数值 `--`、风险显示「未知」、画布中央出现 `bg-offline-notice`；模拟标识始终可见（顶栏 + 模拟条 + 全屏角标三处）。
- 原则三（结构即秩序）：全部尺寸落在 4px 网格；面板靠 1px 发丝边而非阴影。
- 原则四（数据墨水比）：图表去竖直网格、去进度弧、去渐变面积、关平滑。
- 原则五（一套系统七个页面）：页面内联 `<style>` 已收窄为「只写布局」。

### 第二章 设计 token

（`--bg-selected: var(--accent-soft)` 等 9 条，用引用而非重复写值）。

### 第三章 布局架构

- 顶栏 56px，侧栏品牌区 56px，两条下边线对齐成一条水平线（3.3.1）。

- 五档断点：`wide ≥1920 / desktop 1280–1919 / compact 1024–1279 / tablet 769–1023 / mobile ≤768`，
  旧的 760/900/1000/1100 断点全部归并。

## 六、与规范的少量偏离（都有理由）

| 偏离 | 原因 |
|---|---|
| 键值行键列宽 144px（规范 128px） | 「运行时长（顶栏口径）」10 个汉字在 13px 下需要 130px，128px 会被省略号截断；加宽 16px 后所有值仍严格左对齐 |
| 处置队列操作列 104px（规范 88px） | 「确认处理」小号按钮实测需要 74px，扣掉单元格 24px 内边距后 88px 列装不下，会折成两行 |
| 3D 页运行状态文字放左上（规范只说「左下角、工具条上方」） | 规范 4.6.1 的操作提示也要求占「工具条上方 8px」，两者会重叠；把「运行状态」放左上更稳，告警/错误仍按 4.6.5 放左下 |
| 手机端不新增 32px 连接状态通栏（3.4.3） | 各页面内容里已有更具体的就地连接说明（趋势风险条、报警队列标题、设备页连接面板），再加一条通栏是重复信息 |
| `.data-table` 用 `table-layout: fixed` | 默认 auto 布局在 1440px 下会把各列一起压扁成「一字一行」的竖排文字 |
| 窄视口（≤1279px）隐藏图例 / 性能角标 / 运行状态行 | 规范 3.4.2 的 tablet 档本来就规定图例「隐藏，改为按钮弹出」；性能角标是调试件、运行状态行是说明文字，窄屏上三者都会与工具条或跨中读数挤在一起（实测 900/1024 各 2 处重叠） |

## 七、全屏观看模式的返工记录

第一版全屏沿用了旧 P2 的「全屏时把桥型信息卡交还给用户」逻辑，与规范 3.2.3 冲突，
实测在 1440×900 下左上角 **三个块叠在一起**：「模拟」角标 ⨯ 桥型信息卡 ⨯ 运行状态行，
右上角的「退出全屏」按钮还因为内联 SVG 没有固有尺寸被压缩、文字折成两行（「退出全 / 屏」）。

返工内容：

1. **按 3.2.3 的保留清单收口**：全屏只留「视角按钮组 + 图例 + 退出全屏」，
   桥型信息卡与非警告/非加载中的运行状态行一并收起（它们都不在保留清单里，且都落在左上角）。
2. **修按钮折行**：`#fsExit svg { width: 16px; height: 16px; flex: 0 0 auto }` + `white-space: nowrap`。
   内联 SVG 不写 width/height 时浏览器按 300×150 的默认固有尺寸参与 shrink-to-fit 计算，
   按钮被压到 90px、四个汉字只能折行。
3. **图例在全屏保留**（3.2.3 明确要求）；`≤1279px` 时与 tablet 档同口径收起。
4. **跨中读数在全屏时贴顶 16px**（没有指标带了，不必再让到 120px）。
5. **性能角标抬到工具条上方**（`bottom: 90px`）。注意 `hud.js` 的 `PERF_CSS` 是运行时追加到
   `<head>` 的 `<style>`，同特异性下更靠后，所以页面侧必须写成 `.hero-canvas .twin-hud.twin-perf`
   （0,3,0）才能压住它 —— 第一版只写 `.twin-perf` 时被静默覆盖，1024 宽下仍重叠。
6. **信息卡内部行改为单行不折行**：键名在 198px 宽里一折行就变成「主缆 / 中心 / 距」的竖排碎字，
   卡片高度还会翻倍。

验证方式：程序化两两求交，覆盖 6 个视口 × 全屏/普通两种模式 × 深色浅色：

```
900×700  1024×700  1280×800  1440×900  1920×1080  2560×1440
全屏：0 处重叠      普通：0 处重叠
```

（重叠元素集合：指标带、跨中读数、视角工具条三组按钮、操作提示、性能角标、图例、
退出全屏、模拟角标、运行状态行、顶栏。）

截图：`.preview/shots/fullscreen-light.png`、`fullscreen-dark.png`、`fs-900/1024/1280/1920-dark.png`。
